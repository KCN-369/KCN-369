# KCN_LAB · 3D Contribution Viewer

An interactive, rotatable, multi-colour 3D contribution graph — the "adjustable"
companion to the static card in the profile README.

**Live site:** https://kcn-369.github.io/KCN-369/ (published by
`.github/workflows/pages.yml`)

## What it does

* renders one glowing box per contribution day — height = contributions that day
* **drag** to rotate, **scroll** to zoom, or use the yaw / pitch / zoom sliders
* auto-rotate with adjustable speed, plus a reset-view button
* 5 palettes: holographic, aurora, heat, indigo, candy
* switch between years (all years with calendar data are listed)
* hover any pillar for its exact date and contribution count
* live HUD: total, active days, current / longest streak, peak day, level

## Files

| file | purpose |
|:--|:--|
| `index.html` | markup + HUD + control panel |
| `style.css` | light "photon lab" theme |
| `app.js` | dependency-free software 3D renderer (canvas 2D) |
| `data/contrib.json` | data payload — **regenerated by the profile workflow** |

## Regenerating the data

```bash
GITHUB_TOKEN=... python3 scripts/profile_cards.py --user KCN-369 --out profile --data-out docs/data
```

`scripts/profile_cards.py` uses the GitHub GraphQL API and only the Python
standard library. The same workflow run also refreshes the static SVG cards in
`profile/` and the artwork in `assets/`.

## Local preview

```bash
cd docs && python3 -m http.server 8080
# open http://localhost:8080
```
